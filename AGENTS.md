# AGENTS.md

## Objetivo do projeto

Criar um jogo de plataforma 2D educativo sobre a história do Brasil, desde 1500 até os dias atuais.

## Diretrizes gerais

* Trabalhar de forma incremental.
* Sempre priorizar uma versão mínima funcional antes de adicionar complexidade.
* Explicar todas as decisões técnicas.
* Gerar código organizado e modular.
* Explicar como executar e testar cada etapa.
* Não gerar grandes quantidades de código de uma vez.
* Sempre sugerir refatorações simples e expansíveis.
* Preferir clareza e simplicidade ao invés de arquitetura excessivamente complexa.

## Tecnologias preferenciais

* Python como linguagem principal.
* Usar Pygame
* Priorizar ferramentas acessíveis para um programador intermediário em Python.

## Fluxo esperado

* Primeiro definir arquitetura e MVP.
* Depois implementar movimentação básica.
* Depois colisões e plataformas.
* Depois sistema de fases.
* Depois narrativa histórica.
* Depois assets, áudio e polimento.

## Restrições

* Evitar dependências desnecessárias.
* Não criar sistemas avançados prematuramente.
* Sempre validar se a etapa atual está funcionando antes de avançar.
